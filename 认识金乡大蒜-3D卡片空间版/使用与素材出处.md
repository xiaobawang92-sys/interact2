# 认识金乡大蒜 · 3D 液态玻璃卡片空间版

## 使用方法

直接用 **Chrome / Edge / Safari** 双击打开 `index.html` 即可全屏离线运行。

- **5 卡对称 3D 液态玻璃卡片墙**：
  - 聚焦五大科普主题（`01 世界蒜都`、`02 一头金乡蒜`、`03 蒜田里的生长`、`04 从蒜田到餐盘`、`05 一头蒜的远行`），以对称 5 卡 3D 扇形立于空间中；
  - 支持**点击两侧卡片丝滑居中、鼠标左右拖拽、滚轮拨动、键盘 `←`/`→` 切换**；
  - 点击居中主卡或底栏「进入本章探索 ↗」即可展开对应的深度交互科普工作台。
- **底部悬浮科普章节导航 Dock**：采用弹性液态玻璃滑块设计，支持在 3D 卡片墙与详情页中随时一键跳转任意科普主题，彻底服务于科普展陈场景。
- **外观与出处**：右上角可一键切换「暮紫玻璃 / 柔光玻璃」，点击 `i` 图标查看权威数据与实拍出处。
